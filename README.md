# Личный блог [roman-kirillov.ru](https://roman-kirillov.ru)

Блог коуча, пишущего о том, как менять свою жизнь. Задача проекта — простой,
«по-домашнему» сайт без фреймворков, сборщиков и внешней инфраструктуры:
обычные HTML/CSS/JS-файлы, которые открываются двойным кликом из папки.

## Возможности

**Статическая часть (одна колонка, тёмная медовая тема, без зависимостей):**
- Лента постов на главной строится из `posts.js` — простое хранилище текстов
  (свежие сверху), плюс отдельный раздел «Профессиональные статьи»
  (фильтр по категории) и страницы «Обо мне», «Отзывы», «Запись».
- Собственная мини-разметка контента: `**жирный**`, `*курсив*`, маркер,
  изображения, линии, выравнивание строк, рамки-плашки — без Markdown-парсеров.
- `admin.html` — редактор блога без серверной CMS: правка постов и разделов,
  черновики локально в браузере (`localStorage`), публикация постов на хостинг
  одной кнопкой через API.

**Динамическая часть (FastAPI + SQLite одним файлом):**
- Просмотры и голоса за посты, комментарии с ветками-ответами, лайками,
  эмодзи и редактированием своих сообщений.
- Вход по VK для комментариев, заявки на консультацию с антиспам-лимитом,
  отзывы читателей с модерацией.
- Подписка на рассылку + инструмент рассылки писем, уведомления владельцу
  о событиях сайта письмами.
- API-публикация `posts.js` из админки (кнопка «Опубликовать на сайте»).

**SEO и содержание:**
- Метатеги, Open Graph, canonical, JSON-LD для постов, `sitemap.xml`
  перегенерируется сервером при каждой публикации.
- Пинг IndexNow при публикации ускоряет обход Яндекса.
- Политика обработки персональных данных и осознанные согласия на каждой форме.

## Структура

```
index.html        главная (лента + подписка)
post.html         страница поста: post.html?id=<id>
statyi.html       «Профессиональные статьи»
obo-mne.html      «Обо мне»
otzyvy.html       «Отзывы»
zapis.html        «Запись» на консультацию
politika-pd.html  политика обработки персональных данных
posts.js          хранилище постов и текстов разделов (правится из admin.html)
admin.html        редактор блога (только для владельца)
favicon.svg       фавикон — монограмма
server/
  main.py         FastAPI-сервис: комментарии, голоса, заявки, отзывы,
                  подписка/рассылка, VK-вход, публикация, sitemap, IndexNow
  send_newsletter.py  разовая рассылка по подписчикам
publish.ps1       загрузка статических файлов на сервер по scp
*.cmd             ярлыки двойного клика (запуск сервера, проверка индексации)
```

## Запуск локально

Статическую часть можно просто открыть двойным кликом (`index.html`) — сайт
работает и без сервера, динамические секции просто скрываются.

Полная версия (комментарии, заявки, подписка):

```bash
python -m uvicorn server.main:app --port 8000
```

Секреты (ключи и пароли внешних сервисов) лежат в отдельных файлах рядом
с `main.py` и в репозиторий не входят — без них запустятся все статические
и только нейтральные динамические ручки.

## Публикация

`publish.ps1` отправляет статические файлы на сервер по scp (список файлов —
белый списком внутри скрипта; `posts.js` публикуется отдельно из админки,
чтобы не затереть свежую версию). HTTPS — Let's Encrypt с автопродлением.
